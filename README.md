# Python-Assingment1
# Exercise 1: Profit and Revenue Margin
## Description
This program calculates profit and profit margin based on user-provided revenue
and cost values. It demonstrates basic arithmetic operations and user input in
Python.
## Assumptions
- Revenue and cost values are entered as numbers.
- Revenue greater than zero is required to calculate profit margin.

# Exercise 2: Credit Score Evaluator
## Description
This program prompts the user for a credit score and evaluates it using
conditional statements to determine the credit category.
## Assumptions
- Credit scores are entered as integers.
- Scores outside the valid range are considered invalid.

# Exercise 3: Customer Greeting Formatter
## Description
This program formats a personalized customer greeting by cleaning and processing
user input using string methods and functions.
## Assumptions
- The user may enter extra whitespace or multiple names.
- If no name is provided, a default greeting is returned.

# Exercise 4: Tax Bracket Determiner
## Description
This program prompts the user for their annual income and determines their tax
bracket using conditional statements. It then calculates and displays an
estimated tax amount based on the assigned bracket.
## Assumptions
- Income values are entered in dollars.
- A negative income is considered invalid.
- “Deduction Eligible” is a placeholder condition used only to demonstrate a
  ternary expression and does not represent real tax rules.
## Sample Run
What's your annual income? 75000
Your bracket: Medium (20%) (Deduction Eligible). Estimated tax: 15000.0
